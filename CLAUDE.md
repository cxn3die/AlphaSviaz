## Кто и что

- **Заказчик** — ООО «Альфа-Связь», Пенза. Проектирование и монтаж систем
  безопасности: видеонаблюдение, СКУД, пожарная сигнализация, СКС/ВОЛС,
  обслуживание. Входит в группу компаний «Поволжье Строй Сервис».
- **Владелец репозитория** (cxn3die) — подрядчик, делает этот сайт для
  заказчика. Общение на русском.
- **Старый сайт заказчика** — http://acctv.ru/ (Tilda, 2023). Сделан плохо,
  но на нём есть исходная информация: услуги, бренды, кейсы, контакты.
  Векторный логотип взят оттуда.
- **Живой сайт** — https://cxn3die.github.io/AlphaSviaz/ (GitHub Pages).
  Публикуется автоматически из ветки `main` через
  `.github/workflows/deploy.yml`. Ветки сессий Claude (`claude/...`) сами
  по себе не публикуются — только после слияния в `main`.
- Подробности публикации — `ПУБЛИКАЦИЯ.md`. Происхождение фото —
  `ИСТОЧНИКИ-ФОТО.md`. Правила кода — `.cursorrules` (действуют и здесь).

## Решения владельца — не нарушать

- **Подписи логотипов клиентов не трогать.** Имена/alt в
  `lib/data/clients.ts` оставить как есть, даже если не совпадают с
  картинкой. Это прямое указание владельца.
- **Счётчик проектов расчётный, но на сайте об этом нигде не писать**
  (ни «пример», ни «демо», ни «формально»). Позже подключат реальные данные.
- Не выдумывать новые цифры и факты о заказчике. Новое число — только
  после подтверждения. Тексты страниц-источников — черновик, согласовать.
- **Слова не переносятся и не рвутся** нигде на сайте. Не использовать
  `hyphens-auto` и `overflow-wrap:anywhere` (запрет стоит в `globals.css`).
- **9 лет на рынке.** Задано владельцем в `companyFacts` (`lib/data/site.ts`),
  год начала (2017) считается из него. На старом сайте было «12 лет,
  с 2014 года» — владелец решил поставить 9.
- **Шапка везде одинаковая:** прозрачная наверху, тёмное стекло при
  прокрутке. Белой шапки нет. Первый экран каждой внутренней страницы
  заходит под шапку (`-mt-20 pt-20`), иначе сверху видна полоса.
- **Фото должны выглядеть как Россия.** Заказчик работает только в России;
  кадры с европейскими знаками, архитектурой, пальмами и т. п. не годятся.
  Где можно — реальные фото объекта под свободной лицензией (Wikimedia
  Commons с указанием автора). Фото с сайтов компаний и новостей без
  разрешения не брать.
- **Страница проектов:** без плашки «Портфолио объектов», без четырёх блоков
  статистики (они на «О компании»), без фильтра по отраслям, без бейджей
  REC. Кейсы — «журнал объектов» (фото + текст, ряды чередуются).
- **Хлебные крошки показывают реальный путь посетителя**, а не структуру
  сайта (см. «Крошки» ниже).
- **Тексты без «ИИ-шности».** В октябре 2026 владелец утвердил переписанные
  тексты (заголовки, «Почему мы», кейсы, «О компании», источники, нижний
  блок). Правила для новых текстов:
  - короткие простые предложения, факты вместо прилагательных;
  - без противопоставлений «…, а не …» и «не просто …, а …»;
  - без тире посреди фразы («X — Y»), лучше два предложения;
  - без клише: «под ключ» в заголовках, «комплексные решения», «любой
    сложности», «нам доверяют», «лидеры отраслей», «подберём решение»;
  - без канцелярита: «единый контур», «маршрут исполнения», «точка контакта»;
  - не повторять «по всей России» в каждом блоке;
  - новые факты (цены, бесплатность, сроки) — только с подтверждения.
- Фото в кейсах — стоковые, на странице проектов внизу есть сноска, что
  кадры иллюстрируют сценарий. Флаг `illustrative` в `lib/data/projects.ts`
  снимать только вместе с заменой на реальное фото объекта.
- **«О компании», низ страницы:** гарантия и заявка — одна плашка
  (`<PageCtaSection withGuarantee />`): слева «Есть объект?» с кнопками,
  справа «Гарантия до 3 лет», под плашкой строка «Альфа-Связь входит
  в группу компаний «Поволжье Строй Сервис»». Отдельной плашки гарантии
  нет: владелец сказал, что две плашки занимали полэкрана и повторяли
  друг друга.
- **«Как мы ведём проект» — анимированный вариант, компактный.** История:
  анимированный (раскрытие каналов, свет через этапы) владелец сначала
  назвал «ужасно и ИИ-шно»; вариант на фото компании без карточек —
  «говно»; после этого вернул анимированный: «норм, но компактнее».
  На фото и «редакционную» вёрстку не переделывать.
- **Роли команды — простым списком.** Плашку «На связи с вами»
  с мигающей точкой, дерево и бегущий «сигнал» владелец назвал хренью,
  не возвращать. Сетку-чертёж на фоне тоже («тупой фон»). Иллюстрация
  «Услуг» — только по образцу владельца.

## Стек и команды

Next.js 14 (App Router), TypeScript, Tailwind 3, framer-motion,
lucide-react, react-countup. Статический экспорт (`output: "export"`),
`trailingSlash: true`, `basePath` из `NEXT_PUBLIC_BASE_PATH`.

```
npm ci
npm run dev                                   # http://localhost:3000
npx tsc --noEmit -p tsconfig.json
npx next lint
NEXT_PUBLIC_BASE_PATH=/AlphaSviaz npm run build   # сборка как на Pages → out/
```

Проверять сборку под префиксом `/AlphaSviaz/` — так её отдаёт GitHub
Pages. В облачной сессии есть Chromium и Playwright
(`/opt/node-tools/node_modules/playwright`), смотреть минимум 390 и
1440 px, а если трогали шапку — ещё 768, 1024 и 1280.

## Подводные камни (уже наступали)

- **Префикс GitHub Pages.** Файлы из `public` — только через `AppImage`
  (`components/ui/app-image.tsx`) или `assetPath()`. Внутренние ссылки —
  только `next/link`. Сырой `<a href="/privacy">` теряет `/AlphaSviaz` и
  даёт 404.
- **`usePathname` возвращает путь со слэшем** (`/projects/`). Сравнивать
  только через `normalizePath()` из `lib/navigation.ts`, иначе не
  подсвечивается активный пункт меню.
- **Сетка с картой.** У карты `aspect-ratio` + `min-height`, из-за этого
  колонка не сжималась уже 386 px. В сетках брать `grid-cols-1`
  (= `minmax(0,1fr)`) и `min-w-0` у колонок.
- **Шапка.** Брейкпоинты подобраны под ширину логотипа: до `lg` — бургер,
  `lg` — телефон иконкой, с `xl` — номер и часы. Любое изменение логотипа
  или меню — перепроверить 1024/1280/1440.
- **Tailwind.** `duration-[900ms]` неоднозначен из-за `tailwindcss-animate`
  (предупреждение сборки) — писать `[transition-duration:900ms]`.
- **Логотипы клиентов** с `mix-blend-multiply` на тёмной плитке гаснут в
  чёрный — там добавлять `mix-blend-normal`.
- **Большие числа в карточках** — без `tabular-nums` и без разделителя
  тысяч, иначе «100%» и «1149» не влезают в карточку на 1440.
- **Карточки «Цифры и факты»** — `min-h`, а не `h`, плюс `self-start`.
  С жёсткой высотой подпись вылезала за карточку, без `self-start`
  соседние карточки тянутся до одной высоты и ломается «лесенка».
- **Тап на телефоне** присылает и эмулированный `mouseenter` — для
  наведения использовать pointer-события или CSS `group-hover`.
- **`useReducedMotion` в рендере** даёт расхождение гидратации: сайт
  статический, сервер рисует «с движением», браузер сразу «без». React
  оставляет серверные классы, и состояние не обновляется (так этапы на
  «О компании» не загорались). Флаг брать после монтирования, как
  `useStill()` в `AboutProcessTimeline.tsx`. Старые `ClientsMarqueeSection`
  и `BrandDiagonalWatermark` ещё читают его прямо в рендере.

## Счётчик проектов

- `lib/projectCounter.ts`. Опора: **1148 проектов к понедельнику
  05.10.2026**, дальше каждую неделю +2…4 (2 — 70 %, 3 — 20 %, 4 — 10 %),
  сдачи разнесены по дням Пн–Сб, время московское. В среднем ≈10 в месяц —
  столько, по словам владельца, реально закрывается.
- Детерминированный: у всех посетителей одно число, помесячные суммы
  сходятся с итогом, назад не откатывается.
- Где виден: главная (карточка «Проектов»), плашки на `/projects` и
  `/about`, страница `/sources/projects`.
- **Карточка на главной.** Всплывающей плашки нет — владелец попросил
  убрать. Наведение на синюю карточку → прямо под числом «N проекта сдано
  с начала месяца» с медленным серо-белым переливом (`.stat-sheen`).
  Строка мелкая (13/15/18 px) и почти вплотную под цифрами: пустое место
  под цифрами снимает `useNumberMetrics` в `AchievementsSection.tsx`.
  Ширина блока = ширина числа, текст по правому краю. Наведение на строку
  → «в среднем 10 в месяц», тоже по правому краю: у числа и обеих строк
  общая правая граница. На телефоне
  строки появляются сами у середины экрана. Стиль строго деловой.
- Замена на реальные данные: переписать `getProjectStats()`, интерфейс
  `ProjectStats` оставить.
